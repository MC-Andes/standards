# Cómo crear un nuevo proyecto

1. Elegir la plantilla `template-python-mech`, `template-cpp-mech` o
   `template-docs` y seleccionar **Use this template**.
2. Crear el repositorio público en `MC-Andes` con rama `main`.
3. Reemplazar nombres de ejemplo, descripción, autores y `CITATION.cff`.
4. Definir alcance, instalación, ejemplo mínimo y política de soporte.
5. Confirmar que existen `LICENSE`, `CONTRIBUTING.md`, `CHANGELOG.md`,
   `CODEOWNERS`, Dependabot, issue forms y plantilla de Pull Request.
6. Ejecutar lint, pruebas y build de documentación localmente.
7. Activar protección de `main`: Pull Request, una aprobación, descarte de
   aprobaciones obsoletas, conversaciones resueltas y checks requeridos.
8. Habilitar Dependabot alerts, security updates, secret scanning y push
   protection cuando el plan de GitHub lo permita.
9. Añadir el proyecto al sitio y asignar los equipos con mínimo privilegio.
10. Abrir issues de roadmap y publicar `v0.1.0` cuando haya una API utilizable.

# Gobernanza MC-Andes

## Roles

- **Core Maintainers**: definen lineamientos técnicos, aprueban cambios críticos y gestionan releases.
- **Contributors**: proponen cambios mediante PR y mantienen documentación/pruebas de sus aportes.
- **External Collaborators**: colaboraciones puntuales sujetas a revisión de maintainers.

## Principios

- Transparencia técnica (issues, PRs, decisiones documentadas).
- Reproducibilidad (ejemplos, pruebas, documentación).
- Calidad continua (CI obligatoria para merge).
- Escalabilidad por estandarización (templates + políticas comunes).

## Decisiones de base

- Rama principal: `main`
- Flujo: Pull Request obligatorio
- Convención de commits: Conventional Commits
- Versionado: Semantic Versioning (SemVer)
